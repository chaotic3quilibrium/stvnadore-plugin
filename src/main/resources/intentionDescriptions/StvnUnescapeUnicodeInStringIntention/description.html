Decodes lexically safe \uXXXX escape sequences inside a single-line STVN simple string literal ("...") to raw UTF-8 characters.

Decodes paired UTF-16 surrogate escapes (such as \uD83D\uDE80), Zero-Width Joiners (\u200D), variation selectors (\uFE0F), and printable Unicode scalars atomically while keeping lone surrogates, control characters, line separators, quotes (\u0022), backslashes (\u005C), and forbidden bidirectional or invisible format scalars safely escaped.
