Converts an escaped simple string literal into a canonical STVN 2.0.0 fenced string literal ("""[REGEX]...[REGEX]""" or """[RAW]...[RAW]""").

This intention activates only when converting to a fenced string preserves the decoded UTF-8 string value losslessly under Rule STR-04, selecting collision-safe [REGEX] or [RAW] delimiter tags and expanding single-line metadata maps when required.
