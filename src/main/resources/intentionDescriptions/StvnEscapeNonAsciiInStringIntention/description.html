Encodes raw non-ASCII characters (> 0x7F) inside a single-line STVN simple string literal ("...") as uppercase 4-hex \uXXXX escape sequences.

Preserves all existing escape sequences (\n, \r, \t, \", \\, \b, \f, and existing \uXXXX sequences) verbatim while encoding BMP and supplementary UTF-16 surrogate pairs (such as emoji and ZWJ sequences) in canonical uppercase hexadecimal form.
