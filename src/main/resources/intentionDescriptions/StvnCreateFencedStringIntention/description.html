Converts a double-quoted simple string literal ("...") into a canonical STVN 2.0.0 fenced verbatim string block ("""[RAW]...[RAW]""" or """[REGEX]...[REGEX]""") governed by Rule STR-04 (STVN Specification § 5.3).

Decodes simple string escape sequences into verbatim UTF-8 body lines and selects a collision-free uppercase discriminator tag so the closing fence [TAG]""" matches the opening fence """[TAG].
