Converts an escape-free double-quoted simple string literal ("...") or incomplete fenced opener into a canonical STVN 2.0.0 fenced verbatim string block ("""[RAW]...[RAW]""" or """[REGEX]...[REGEX]""") governed by Rule STR-04 (STVN Specification § 5.3).

Preserves UTF-8 text verbatim and selects a collision-free uppercase discriminator tag so the closing fence [TAG]""" matches the opening fence """[TAG].
