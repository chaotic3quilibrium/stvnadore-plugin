Converts a valid STVN 2.0.0 Rule STR-04 fenced string block ("""[TAG]...[TAG]""") into a canonically escaped single-line double-quoted string literal ("...").

Decodes the fenced string body using context-sensitive #preserveIndent rules (always stripping common leading ASCII-space indentation on inline #regex and string bound facets per STVN Specification § 5.3) and escapes quotes, backslashes, tabs, and line breaks for lossless round-trip closure.
