Validates fenced string literals against Rule STR-04 (Fenced String Language Discriminator Invariant).

Every fenced string literal must comply with the following invariants:

  • Opening Delimiter: Must start with """->[TAG] or """[TAG], followed by optional horizontal whitespace and a newline.
  • Closing Delimiter: Must end with [TAG]""", where the closing tag matches the opening tag identically.
  • Character Constraints: The tag must match positive character class ^[a-zA-Z0-9_-]{1,256}$.
  • Prohibited Patterns: Empty tags ([]), whitespace, quotation marks, and punctuation characters are disallowed.
  • Recursive Nesting: Fenced string literals may nest arbitrarily. Outer blocks encapsulate inner blocks with distinct tags.

Quick-Fixes Available:

  • Atomically supply default tag [FENCE] and generate matching closing delimiter.
  • Strip whitespace and illegal characters from delimiter tags.
  • Balance mismatched closing tags to match the opening tag (available on both opening and closing lines).
  • Balance mismatched opening tags to match the closing tag (available on both opening and closing lines).
  • Append missing closing delimiter directly on the line below unclosed blocks.
