Audits metadata facet sequence in root :meta blocks (canonical 3-tier order: #name → #domain → #kind, STVN Spec §3.10.1) and in nominal type definitions and schema expressions to enforce the canonical 5-tier Semantic Category Order hierarchy (STVN Spec §6.1).

Canonical 5-Tier Semantic Category Order:

  1. Tier 1 (Definition): #unsigned → #exact → #invertible → #ns..#s → #offset..#audited → #size → #minSize → #maxSize
  2. Tier 2 (Trait): #equatable → #comparable
  3. Tier 3 (Bounds): #minIncl → #minExcl → #maxIncl → #maxExcl
  4. Tier 4 (Constraint): #filterIncl → #filterExcl → #preserveIndent → #regex
  5. Tier 5 (Directive): #strip

Mutex-Group Rank Stabilization:

When two facets from the same mutually exclusive group co-occur in reverse sub-rank order (#ns..#s, #offset..#audited, #size/#exact, #minIncl/#minExcl, #maxIncl/#maxExcl, or #filterIncl/#filterExcl), secondary order cascades are suppressed and StvnReorderMetadataFacetsQuickFix preserves the authored relative order within that group so E008 / MUTUALLY_EXCLUSIVE_BOUNDS remains pinned exclusively to the conflicting facet.

Facets declared out of tier order trigger E037 / ERR_FACET_ORDER_VIOLATION with an automated quick-fix to restore canonical 5-tier order.
