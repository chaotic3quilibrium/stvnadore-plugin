Audits metadata facet sequence in nominal type definitions and compile-time constants to enforce the canonical 7-tier Semantic Category Order hierarchy.

Canonical 7-Tier Semantic Category Order:

  1. Tier 1 (Flags & Intrinsic Modes): #unsigned → #exact → #invertible → #preserveIndent → #offset → #zoned → #audited → #equatable → #comparable
  2. Tier 2 (Temporal Scale): #s → #ms → #us → #ns
  3. Tier 3 (Dimensions & Capacity): #size → #minSize → #maxSize
  4. Tier 4 (Value Intervals): #minIncl → #minExcl → #maxExcl → #maxIncl
  5. Tier 5 (Validation Patterns): #regex
  6. Tier 6 (Domain Subsets): #filterIncl → #filterExcl
  7. Tier 7 (Directives): #strip

Facets declared out of tier order or out of relative order within their tier trigger a weak warning. An automated quick-fix is provided to restore canonical 7-tier order.
