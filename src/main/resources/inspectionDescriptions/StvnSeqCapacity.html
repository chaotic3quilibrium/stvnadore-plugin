Validates that root :Seq schema declarations specify explicit capacity facets within configured element limits (STVN Spec § 5.5.3 and § 6.1).

STVN defines a default allocation ceiling of 16,777,216 elements for unadorned :Seq constructors. This inspection governs :Seq schemas exclusively under STVN | Governance | Capacity, flagging root :Seq(...) constructors lacking explicit capacity facets (PW001) or specifying #maxSize above the configured threshold (default: 4,096 elements, PW003). Derived nominal aliases (:ChildSeq :ParentSeq) inherit locked Tier-1 bounds from their root constructor and are not flagged. Immutable constant declarations (#CONST :Seq(:Int) [...]) omit unadorned warnings while still reporting PW003 when explicit #maxSize exceeds the threshold.

QuickFix Resolution Protocol:

  • Under WARNING / WEAK WARNING severity: Offers threshold quick-fixes (#maxSize N, 0..N, 1..N) and default allocation cap quick-fixes (16777216) inserted at canonical 5-tier metadata rank.
  • Under ERROR severity: Suppresses the 16777216 quick-fixes so applied fixes satisfy the configured error threshold.

Payload and Constant Literal Scope (Optional):

When Inspect sequence literals in body payloads and constants is enabled, flags [...] sequence literals governed by :Seq in :body and #CONST definitions whose element count exceeds the active bound (PW004), offering quick-fixes to truncate excess elements or widen the governing :Seq schema #maxSize.

Example (Violation):

:defs {
  :SampleSeries :Seq(:Int)
}

Example (Compliant):

:defs {
  :SampleSeries { #minSize 1 #maxSize 1024 } :Seq(:Int)
}
