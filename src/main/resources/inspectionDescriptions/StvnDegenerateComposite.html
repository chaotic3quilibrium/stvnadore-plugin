Reports degenerate arity-1 composite schema definitions (:Enum, :Union, :Tuple) that offer zero branching entropy or redundant container wrapping.

In algebraic type systems, composites containing exactly one component are isomorphic to simpler forms:

  • Single-Variant Enum (:Enum [ #Variant ]): An enumeration with only 1 variant has 0 bits of information entropy. It acts as a static constant rather than a branching state machine.
  • Single-Branch Union (:Union( :T )): A coproduct with a single branch (:T + ∅ ≅ :T) offers no alternative branches or polymorphic dispatch.
  • Single-Element Tuple (:Tuple( :T )): A Cartesian product with one factor (:T × 1 ≅ :T) adds redundant parenthesis wrapping without positional decomposition benefits.

Quick-Fix Available:

  • Unwrap degenerate composite to ':T': Atomically replaces :Union( :T ) or :Tuple( :T ) with the inner schema type :T.

Anti-Pattern Example:

{
  :defs {
    :Status :Enum [ #Active ]       // Warning: 0 branching entropy
    :SingleBranch :Union( :String ) // Warning: Isomorphic to :String
    :WrappedId :Tuple( :Int64 )      // Warning: Redundant container wrapping
  }
  :type :Tuple( :Status :SingleBranch :WrappedId )
  :body ...
}

Canonical Unwrapped Schema:

{
  :defs {
    :SingleBranch :String           // Unwrapped
    :WrappedId :Int64               // Unwrapped
  }
  :type :Tuple( :Enum [ #Active #Inactive ] :SingleBranch :WrappedId )
  :body ...
}
