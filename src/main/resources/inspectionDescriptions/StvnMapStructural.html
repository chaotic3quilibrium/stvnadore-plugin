Detects flat sequence literals ([...]) placed in slot positions requiring associative map structures ({...}) according to the resolved STVN schema (STVN Spec § 5.5.1 and § 5.5.4).

In STVN, associative maps (:Map and { #invertible } :Map) require a map envelope containing ordered key-value pairs wrapped in brackets: {[key value] ...}. Placing a flat list [key1 val1 key2 val2] directly into a map slot is a structural type violation.

Quick-Fix Available:

Press Alt+Enter (macOS: ⌥Enter) on the highlighted flat list to invoke the Convert to Map Literal auto-healer. The quick-fix partitions the sequence elements into pairwise [key value] entries enclosed within canonical map braces { ... }.

Example (Incorrect):

{
  :type :Map(:String :Int)
  // Structural Error: Flat list in map slot
  :body ["alice" 100 "bob" 200]
}

After Applying Quick-Fix:

{
  :type :Map(:String :Int)
  // Valid canonical map literal envelope
  :body {
    ["alice" 100]
    ["bob"   200]
  }
}
