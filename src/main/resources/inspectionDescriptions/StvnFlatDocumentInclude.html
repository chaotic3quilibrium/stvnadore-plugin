Detects forbidden :include statements inside hermetic documents (.stvn) and hermetic definitions schemas (.stvn_d).

Hermetic documents and definitions schemas must remain completely self-contained and cannot contain include directives under STVN 2.0.0 Specification § 1.2.

Example (Prohibited Include in Hermetic Document):

// Inside file.stvn
:defs {
  // Error: Hermetic document or schema (.stvn / .stvn_d) cannot contain include statements
  :include [ "types.stvn_d" ]
}
