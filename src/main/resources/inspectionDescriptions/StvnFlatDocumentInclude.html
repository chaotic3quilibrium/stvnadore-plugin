Detects prohibited :include statements and external-package :use directives inside hermetic documents (.stvn, .stvn_d, .stvn_b, .stvn_bd).

Hermetic compilation units must remain self-contained under STVN 2.0.0 Specification § 1.2 and § 3.9. A hermetic file cannot declare :include directives (E005), and scoped :use directives can target only Standard Library Prelude packages or non-reserved packages declared locally in the same :defs section (E035).

Example (Prohibited Include and External Package Import in Hermetic Document):

// Inside file.stvn
:defs {
  // E005: Hermetic document or schema (.stvn, .stvn_d, .stvn_b, .stvn_bd) cannot contain include statements: file.stvn
  :include [ "types.stvn_d" ]

  // E035: Scoped :use in hermetic document cannot target external package
  :use [ :external/unloaded/billing { #strip } ]
}

Use the quick-fixes to search available packages, remove the prohibited :include directive or unresolved :use package entry, or convert a textual file to modular format (.stvn_i or .stvn_di) when importing external workspace modules.
