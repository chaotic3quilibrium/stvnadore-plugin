Detects module :include and lexical :use violations across hermetic and modular STVN compilation units.

Enforces STVN 2.0.0 Specification § 1.2, § 3.9, and § 4.2 module isolation and namespace rules:

  • Prohibits :include statements inside hermetic documents (E005) and external-package :use targets outside Prelude and locally declared non-reserved packages (E035).
  • Flags illegal modifier blocks inside :include [...] (E002), offering Remove illegal modifier from ':include'.
  • Flags duplicate same-scope :use package targets and duplicate (LHS, RHS) alias mappings (E005), offering Remove duplicate ':use' entry and Remove duplicate ':use' alias mapping.
  • Flags coordinate-pinned :use and unpackaged :include namespace collisions (E006), offering Replace '#strip' with explicit symbol aliases on colliding { #strip } directives.

Example:

:defs {
  // E005: Duplicate ':use' target ':subsea/pump/primary' in the same scope
  :use [
    :subsea/pump/primary { #strip }
    :subsea/pump/primary { #strip }
    :subsea/pump/raman { #strip } // E006: Replace '#strip' with explicit symbol aliases
  ]
}
