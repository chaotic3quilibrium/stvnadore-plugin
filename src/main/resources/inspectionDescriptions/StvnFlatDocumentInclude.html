Detects forbidden :include statements inside hermetic flat documents (.stvn_f) and flat leaf modules (.stvn_inclf).

Flat documents and leaf include modules must remain completely self-contained and cannot contain include directives.

Example (Prohibited Include in Flat File):

// Inside file.stvn_f
:defs {
  // Error: Flat document or leaf module (.stvn_f / .stvn_inclf) cannot contain include statements
  :include [ "types.stvn_incl" ]
}
