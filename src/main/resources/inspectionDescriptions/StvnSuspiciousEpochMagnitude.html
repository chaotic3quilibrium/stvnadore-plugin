Reports integer literals in :body bound to :TimeEpoch whose digit length mismatches the declared scale flag by ≥ 3 orders of magnitude.

Under STVN Language Specification § 5.6.1, :TimeEpoch denotes discrete duration since Unix Epoch (1970-01-01T00:00:00Z) qualified by an explicit bare scale flag (#s, #ms, #us, or #ns).

Developers frequently paste millisecond or nanosecond timestamps into seconds-resolution schemas, causing computed calendar dates to resolve tens of thousands of years into the future.

Magnitude Bands:

  • Seconds (#s): 9..10 digits (e.g. 1704067200)
  • Milliseconds (#ms): 12..13 digits (e.g. 1704067200000)
  • Microseconds (#us): 15..16 digits (e.g. 1704067200000000)
  • Nanoseconds (#ns): 18..19 digits (e.g. 1704067200000000000)

Compliant Example:

{
  :defs {
    :CreatedEpoch { #s } :TimeEpoch
  }
  :type :CreatedEpoch
  :body 1704067200
}

Warning Example:

{
  :defs {
    :CreatedEpoch { #s } :TimeEpoch
  }
  :type :CreatedEpoch
  // Warning: 13 digits indicate milliseconds, but schema declared seconds #s
  :body 1704067200000
}

Available Quick-Fixes:

  • Rescale literal: Divides or multiplies the literal value to align with the declared schema scale.
  • Update schema scale flag: Replaces the scale flag in the local schema definition to match the literal magnitude band.
