Flags fundamental scalar and structural types declared on the left-hand side (LHS) of a type definition.

STVN prohibits redefining or aliasing built-in fundamental keywords (such as :Int, :Float, :Boolean, :String, :TimeEpoch, :DateTime, or :Tuple). Fundamental type keywords cannot be aliased.

Example (LHS Violation):

:defs {
  // Error: Fundamental type ':Int' cannot be aliased
  :Int :MyInt
}
