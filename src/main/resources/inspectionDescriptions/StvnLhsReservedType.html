Flags fundamental scalar and structural types declared on the left-hand side (LHS) of a type definition.

STVN prohibits redefining or aliasing built-in fundamental keywords (such as :Int32, :Boolean, :String, or :Tuple). Fundamental type keywords cannot be aliased.

Example (LHS Violation):

:defs {
  // Error: Fundamental type ':Int32' cannot be aliased
  :Int32 :Int64
}
