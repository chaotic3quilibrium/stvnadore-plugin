Reports redundant metadata facets (Rule W003 / WARN_REDUNDANT_METADATA_FACET) across nominal type definitions, root :type declarations, constant definitions, and inline schema constructors.

Under STVN 2.0.0 (Core Rule W003), tautological metadata facets emit non-blocking compiler warnings (WARN_REDUNDANT_METADATA_FACET). Tautologies are purged during semantic IR lowering to guarantee bitwise-identical Content-Addressable Storage (CAS) hashes without halting compilation.

This inspection mirrors stvnadore-core Rule W003 1:1 across intrinsic base defaults (such as #size 32 on :Int, #size 64 on continuous :Float, #minSize 0, #maxSize 16777216, #preserveIndent #FALSE on :String, natural bit-width bounds, and intrinsic #equatable / #comparable traits) as well as redundant nominal-parent overrides across :Int, :Float, :String, :TimeEpoch, :DateTime, and :Enum subsets, providing an automated quick-fix to remove the redundant facet.

Quick-Fix: Removes the redundant facet declaration. If the metadata map contains only the redundant facet, the enclosing braces {} are cleanly excised automatically to prevent triggering empty metadata block errors (ERR_EMPTY_METADATA_BLOCK).
