Detects redundant metadata facet overrides in nominal type definitions within :defs blocks.

A metadata facet declaration is redundant when the parent type's resolved schema already possesses an identical effective value. Redeclaring the same constraint adds noise and obscures intentional overrides.

Examples:

  • Declaring { #preserveIndent #FALSE } on a type derived from :String (which already defaults to #FALSE).
  • Declaring { #preserveIndent #TRUE } on a type whose parent already declared or inherited #preserveIndent #TRUE.
  • Declaring { #maxSize 16777216 } or { #minSize 0 } on unconstrained string aliases.

Quick-Fix: Removes the redundant facet declaration. If the metadata map contains only the redundant facet, the enclosing braces {} are removed automatically.
