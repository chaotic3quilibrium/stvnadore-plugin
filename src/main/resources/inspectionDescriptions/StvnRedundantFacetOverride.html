Reports redundant metadata facet overrides in nominal type definitions within :defs blocks.

Under STVN 2.0.0 (Core Rule W003), tautological metadata facets emit non-blocking compiler warnings (WARN_REDUNDANT_METADATA_FACET). Tautologies are purged during semantic IR lowering to guarantee bitwise-identical Content-Addressable Storage (CAS) hashes without halting compilation.

This inspection audits non-fatal nominal inheritance overrides (such as redundant #preserveIndent #FALSE on unconstrained string aliases or identical capacity bounds) and provides an automated quick-fix to remove the redundant facet.

Quick-Fix: Removes the redundant facet declaration. If the metadata map contains only the redundant facet, the enclosing braces {} are cleanly excised automatically to prevent triggering empty metadata block errors (ERR_EMPTY_METADATA_BLOCK).
