Validates that root :Set schema declarations specify explicit capacity facets within configured element limits (STVN Spec § 5.5.3 and § 6.1).

STVN defines a default allocation ceiling of 16,777,216 elements for unadorned :Set constructors. This inspection governs :Set schemas exclusively under STVN | Governance | Capacity, flagging root :Set(...) constructors lacking explicit capacity facets (PW001) or specifying #maxSize above the configured threshold (default: 4,096 elements, PW003). Derived nominal aliases (:ChildSet :ParentSet) inherit locked Tier-1 bounds from their root constructor and are not flagged. Immutable constant declarations (#CONST :Set(:Int) [...]) omit unadorned warnings while still reporting PW003 when explicit #maxSize exceeds the threshold.

QuickFix Resolution Protocol:

  • Under WARNING / WEAK WARNING severity: Offers threshold quick-fixes (#maxSize N, 0..N, 1..N) and default allocation cap quick-fixes (16777216) inserted at canonical 5-tier metadata rank.
  • Under ERROR severity: Suppresses the 16777216 quick-fixes so applied fixes satisfy the configured error threshold.

Payload and Constant Literal Scope (Optional):

When Inspect set literals in body payloads and constants is enabled, flags [...] set literals governed by :Set in :body and #CONST definitions whose element count exceeds the active bound (PW004), offering quick-fixes to truncate excess elements or widen the governing :Set schema #maxSize.

Example (Violation):

:defs {
  :AllowedPorts :Set(:Int)
}

Example (Compliant):

:defs {
  :AllowedPorts { #minSize 1 #maxSize 128 } :Set(:Int)
}
