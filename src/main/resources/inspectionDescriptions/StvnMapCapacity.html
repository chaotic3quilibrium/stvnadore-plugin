Validates that root :Map schema declarations specify explicit capacity facets within configured entry limits (STVN Spec § 5.5.3 and § 6.1).

STVN defines a default allocation ceiling of 16,777,216 entries for unadorned :Map constructors. This inspection governs :Map schemas exclusively under STVN | Governance | Capacity, flagging root :Map(...) constructors lacking explicit capacity facets (PW001) or specifying #maxSize above the configured threshold (default: 4,096 entries, PW003). Derived nominal aliases (:ChildMap :ParentMap) inherit locked Tier-1 bounds from their root constructor and are not flagged. Immutable constant declarations (#CONST :Map(:String :Int) {...}) omit unadorned warnings while still reporting PW003 when explicit #maxSize exceeds the threshold.

QuickFix Resolution Protocol:

  • Under WARNING / WEAK WARNING severity: Offers threshold quick-fixes (#maxSize N, 0..N, 1..N) and default allocation cap quick-fixes (16777216) inserted at canonical 5-tier metadata rank.
  • Under ERROR severity: Suppresses the 16777216 quick-fixes so applied fixes satisfy the configured error threshold.

Payload and Constant Literal Scope (Optional):

When Inspect map literals in body payloads and constants is enabled, flags { [key value] ... } map literals in :body and #CONST definitions whose entry count exceeds the active bound (PW004), offering quick-fixes to truncate excess entries or widen the governing :Map schema #maxSize.

Example (Violation):

:defs {
  :ZoneFlowMap :Map(:String :Int)
}

Example (Compliant):

:defs {
  :ZoneFlowMap { #minSize 1 #maxSize 256 } :Map({ #minSize 1 #maxSize 64 } :String :Int)
}
