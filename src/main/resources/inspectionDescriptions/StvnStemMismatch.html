Audits document metadata declarations to ensure that declared #name and #domain facets match the filename stem hierarchy.

Filename stem slot 0 corresponds to the declared document #name. Filename stem slot 1 corresponds to the optional declared document #domain.

When declared #name differs from slot 0, warning WARN_DOCUMENT_NAME_MISMATCH is emitted. When declared #domain is omitted from slot 1, warning WARN_DOCUMENT_DOMAIN_OMITTED_IN_FILENAME is emitted.

Quick-Fix:

Renames the #name string literal to match the active file stem slot 0.

Renames the file to include the declared domain in filename stem slot 1 (e.g. name.domain.stvn_i).

Removes the optional #domain attribute from the root :meta block.
