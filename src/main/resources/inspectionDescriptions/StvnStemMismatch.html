Audits document metadata declarations to ensure that declared #name and #domain facets match the filename stem hierarchy.

Filename stem slot 0 corresponds to the declared document #name. Filename stem slot 1 corresponds to the optional declared document #domain.

When declared #name differs from slot 0, warning WARN_DOCUMENT_NAME_MISMATCH is emitted. When declared #domain is omitted from slot 1, warning WARN_DOCUMENT_DOMAIN_OMITTED_IN_FILENAME is emitted. When a user document declares a reserved system domain starting with stvn_, error ERR_RESERVED_DOMAIN_PROHIBITED (E038) is emitted.

Quick-Fix:

Renames the #name or #domain string literal to match the active file stem slot.

Renames the file to include a valid non-reserved declared domain in filename stem slot 1 (e.g. name.domain.stvn_i).

Removes the optional #domain attribute or strips the reserved stvn_ prefix from the root :meta block.
