Detects unresolved type references in Strongly Typed Value Notation (STVN) documents.

When an unadorned nominal type matches a known definition in the Standard Library Prelude (:org/stvnadore/prelude/*), this inspection flags the bare symbol and offers quick-fixes to:

  • Qualify the symbol in-place with its canonical fully qualified nominal identifier (FQNI).
  • Import the symbol into the document scope via a :use statement in :defs.
  • Brand a local nominal type in :defs that aliases the Prelude type.

This inspection supports batch execution across the entire active file.
