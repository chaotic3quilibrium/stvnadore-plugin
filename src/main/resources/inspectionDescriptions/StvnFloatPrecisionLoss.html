Reports floating-point literals whose decimal precision exceeds the physical mantissa capacity of continuous IEEE-754 Single (32-bit) or Double (64-bit) floating-point types.

Under STVN Language Specification § 5.1.3:

  • Continuous 32-bit floats ({ #size 32 } :Float) possess 24 bits of mantissa (∼7.22 significant decimal digits). Literals exceeding 7 decimal digits suffer truncation and rounding during binary encoding.
  • Continuous 64-bit floats (:Float / { #size 64 } :Float) possess 53 bits of mantissa (∼15.95 significant decimal digits). Literals exceeding 17 decimal digits suffer truncation and rounding during binary encoding.
  • Discrete exact floats ({ #exact } :Float) implement arbitrary-precision decimal representations (≤ 16,777,216 digits) and remain completely unaffected by this inspection.

Compliant Examples:

// Compliant: Fits within Single (32-bit) precision (≤ 7 digits)
:Speed { #size 32 } :Float
#1 42.12345

// Compliant: Fits within Double (64-bit) precision (≤ 17 digits)
:Coordinates :Float
#2 3.141592653589793

// Compliant: Arbitrary precision decimal arithmetic
:PreciseValue { #exact } :Float
#3 3.1415926535897932384626433832795028841971

Warning Examples:

// Warning: 20 digits written to 32-bit float; truncates to 42.123455
#1 42.1234567890123456789

// Warning: 22 digits written to 64-bit float; truncates to 3.141592653589793
3.1415926535897932384626

Available Quick-Fixes:

  • Round literal to nearest IEEE-754 representation: Replaces the authored literal with the exact truncated and rounded IEEE-754 value that binary encoding produces.
  • Switch variant to exact float branch: When the literal resides within a tagged union variant with a sibling declaring { #exact } :Float, switches the variant tag to select the exact arbitrary-precision branch.
