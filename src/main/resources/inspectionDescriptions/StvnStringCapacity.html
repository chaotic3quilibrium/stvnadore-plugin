Validates that nominal string type declarations adhere to capacity governance policies by specifying explicit capacity facets within configured allocation limits (STVN Spec § 5.3).

STVN defines a default allocation capacity of 16 MiB (16,777,216 characters) for unadorned :String types. This inspection identifies unadorned :String tokens lacking capacity metadata facets and explicit capacity bounds exceeding the configured threshold (default: 4,096 characters).

QuickFix Resolution Protocol:

  • Under WARNING / WEAK WARNING severity:
    • Primary QuickFix: Rewrites the nominal type with explicit threshold facets (e.g. { #minSize 1 #maxSize 4096 } :String).
    • Secondary QuickFix: Rewrites the nominal type to the default capacity (e.g. { #minSize 1 #maxSize 16777216 } :String).
  • Under ERROR severity:
    • Presents only the Primary QuickFix ({ #minSize 1 #maxSize 4096 } :String). Upgrading to 16,777,216 is suppressed because that value itself violates the error threshold.

Payload Scope (Optional):

When payload scanning is enabled in inspection settings, flags runtime string literals in :body blocks and constant definitions whose text length exceeds the bound declared in the active schema. Provides quick-fixes to truncate the literal or widen the schema capacity.

Example (Violation):

:defs {
  // Warning: Unadorned :String defaults to 16 MiB default capacity
  :Username :String
}

Example (Compliant):

:defs {
  :Username { #minSize 1 #maxSize 64 } :String
  :PayloadBuffer { #minSize 1 #maxSize 4096 } :String
}
