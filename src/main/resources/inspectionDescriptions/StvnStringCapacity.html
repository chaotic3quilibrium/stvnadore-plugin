Validates that nominal string type declarations adhere to capacity governance policies by specifying explicit capacity bounds within configured allocation limits.

STVN defines a default allocation capacity of 16 MiB (16,777,216 characters) for unadorned :String types. This inspection identifies unadorned string tokens (such as :String, :StringFixed, and :StringNonEmpty) and explicit capacity suffixes exceeding the configured threshold (default: 4,096 characters).

QuickFix Resolution Protocol:

  • Under WARNING / WEAK WARNING severity:
    • Primary QuickFix: Rewrites the nominal type to the configured threshold (e.g. :String → :String4096).
    • Secondary QuickFix: Rewrites the nominal type to the default capacity (e.g. :String → :String16777216).
  • Under ERROR severity:
    • Presents only the Primary QuickFix (:String4096). Upgrading to 16,777,216 is suppressed because that value itself violates the error threshold.

Payload Scope (Optional):

When payload scanning is enabled in inspection settings, flags runtime string literals in :body blocks and constant definitions whose text length exceeds the bound declared in the active schema. Provides quick-fixes to truncate the literal or widen the schema capacity.

Example (Violation):

:defs {
  // Warning: Unadorned :String defaults to 16 MiB default capacity
  :Username :String

  // Warning: Capacity 8192 exceeds configured threshold 4096
  :PayloadBuffer :String8192
}

Example (Compliant):

:defs {
  :Username :String64
  :PayloadBuffer :String4096
}
