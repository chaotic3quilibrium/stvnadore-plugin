Validates that root :String schema declarations specify explicit capacity facets within configured character limits (STVN Spec § 5.1.5 and § 6.1).

STVN defines a default allocation capacity of 16,777,216 Unicode Scalar Values for unadorned :String types. This inspection governs :String schemas exclusively under STVN | Governance | Capacity (peer collection inspections govern :Map, :Seq, and :Set independently). It flags root :String constructors lacking explicit capacity facets (PW002) or specifying #maxSize above the configured threshold (default: 4,096 characters, PW003). Derived nominal aliases (:ChildStr :ParentStr) inherit locked Tier-1 capacity bounds from their root constructor and are not flagged. Immutable compile-time constant declarations (#CONST :String "...") omit unadorned warnings while still reporting PW003 when explicit #maxSize exceeds the threshold.

QuickFix Resolution Protocol:

  • Under WARNING / WEAK WARNING severity:
    • Fix 1: { #maxSize 4096 } ("Set nominal capacity to 4096")
    • Fix 2: { #minSize 0 #maxSize 4096 } ("Set nominal capacity to 0..4096 (allow empty)")
    • Fix 3: { #minSize 1 #maxSize 4096 } ("Set nominal capacity to 1..4096 (non-empty)")
    • Fix 4: { #maxSize 16777216 } ("Set nominal capacity to 16777216 (default allocation cap)")
    • Fix 5: { #minSize 0 #maxSize 16777216 } ("Set nominal capacity to 0..16777216 (allow empty)")
    • Fix 6: { #minSize 1 #maxSize 16777216 } ("Set nominal capacity to 1..16777216 (non-empty)")
  • Under ERROR severity:
    • Presents only threshold QuickFixes (Fixes 1, 2, and 3). Default allocation cap QuickFixes (Fixes 4, 5, and 6) are suppressed because 16,777,216 violates the error threshold.

Payload and Constant Literal Scope (Optional):

When Inspect string literals in body payloads and constants is enabled, flags string literals in :body blocks and #CONST definitions whose decoded Unicode code-point length exceeds the active bound (PW004), providing quick-fixes to truncate the literal or widen the governing :String schema capacity.

Example (Violation):

:defs {
  :Username :String
}

Example (Compliant):

:defs {
  :Username { #minSize 1 #maxSize 64 } :String
}
