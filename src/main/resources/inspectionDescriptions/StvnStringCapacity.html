Validates that nominal string and collection type declarations adhere to capacity governance policies by specifying explicit capacity facets within configured allocation limits (STVN Spec § 5.3).

STVN defines a default allocation capacity of 16 MiB (16,777,216 characters or elements) for unadorned :String, :Seq, :Set, and :Map types. This inspection identifies unadorned tokens lacking capacity metadata facets and explicit capacity bounds exceeding the configured threshold (default: 4,096 characters or elements).

QuickFix Resolution Protocol:

  • Under WARNING / WEAK WARNING severity:
    • Fix 1: { #maxSize 4096 } ("Set nominal capacity to 4096")
    • Fix 2: { #minSize 0 #maxSize 4096 } ("Set nominal capacity to 0..4096 (allow empty)")
    • Fix 3: { #minSize 1 #maxSize 4096 } ("Set nominal capacity to 1..4096 (non-empty)")
    • Fix 4: { #maxSize 16777216 } ("Set nominal capacity to 16777216 (default allocation cap)")
    • Fix 5: { #minSize 0 #maxSize 16777216 } ("Set nominal capacity to 0..16777216 (allow empty)")
    • Fix 6: { #minSize 1 #maxSize 16777216 } ("Set nominal capacity to 1..16777216 (non-empty)")
  • Under ERROR severity:
    • Presents only threshold QuickFixes (Fixes 1, 2, and 3). Default allocation cap QuickFixes (Fixes 4, 5, and 6) are suppressed because 16,777,216 violates the error threshold.

Payload Scope (Optional):

When payload scanning is enabled in inspection settings, flags runtime string literals in :body blocks and constant definitions whose text length exceeds the bound declared in the active schema. Provides quick-fixes to truncate the literal or widen the schema capacity.

Example (Violation):

:defs {
  :Username :String
  :Identifiers :Seq( :Int )
}

Example (Compliant):

:defs {
  :Username { #minSize 1 #maxSize 64 } :String
  :Identifiers { #maxSize 4096 } :Seq( :Int )
}
