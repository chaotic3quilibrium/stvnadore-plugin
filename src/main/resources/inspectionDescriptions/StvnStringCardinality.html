Reports invalid string cardinality facets on :String type declarations under STVN 2.0.0 § 6.1.

String Cardinality Invariant (E008 / ERR_STRING_CARDINALITY_PROHIBITED):

  • The #size facet represents physical bit-width and is prohibited on :String declarations.
  • Declare string character bounds with #minSize and #maxSize at canonical Tier 1.5 position (for example, { #minSize 1 #maxSize 64 } :String).

Available Quick-Fixes:

  • Convert positive #size <N> to upper-bounded #maxSize <N> (primary action, preserving compatible #minSize bounds).
  • Convert positive #size <N> to bounded non-empty #minSize 1 #maxSize <N>.
  • Convert positive #size <N> to fixed-length #minSize <N> #maxSize <N>.
  • Use default 16777216 :String capacity when #size 16777216 matches the intrinsic ceiling without introducing redundant #maxSize warnings.
  • Remove prohibited #size facets when non-positive or declared on derived nominal aliases.
