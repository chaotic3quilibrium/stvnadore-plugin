Reports invalid string cardinality facets on string type declarations to enforce STVN 2.0.0 governance (MCT § 3.1.3).

String Cardinality Invariant (ERR_INVALID_METADATA_FACET):

  • The #size facet represents physical bit-width and is prohibited on :String declarations.
  • Character bounds for strings must be declared using #minSize and #maxSize (e.g. { #minSize 1 #maxSize 64 } :String).

Provides an automated intention quick-fix to convert #size <N> into #minSize 1 #maxSize <N>.
