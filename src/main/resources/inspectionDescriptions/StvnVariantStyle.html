Reports style discrepancies and redundant discriminator tags on algebraic sum types (:Option, :Either, :Union) and boolean literals according to project code style preferences.

This inspection enforces two distinct style rules:

  1. Redundant Variant Tags: When "Prefer Implied Sum Types" is enabled in project settings, explicit tags on unambiguous payload variants are flagged as redundant:
    • #Some "text" in :Option(:String) (Rule A inference)
    • #Right 42 in :Either(:String :Int32) (Rule B inference)
    • #1 "payload" in :Union(:String :Int32) (Rule C inference)
  2. Form Discrepancies (Long vs. Short): Flags sum-type tags and boolean literals that do not match the configured long-form or short-form style preference:
    • Long Form: #Some, #None, #Left, #Right, #TRUE, #FALSE
    • Short Form: #S, #N, #L, #R, #T, #F
    Note: Numeric union branch tags (e.g. #1, #2) possess invariant fixed syntax.

Quick-Fixes Available:

  • Remove redundant tag: Strips the superfluous discriminator tag (#Some, #Right, #1, etc.), leaving the clean inferred payload literal.
  • Change tag to #...: Converts short-form tags to long-form or vice versa to align with project settings.

Example (Redundant Tag & Form Discrepancy):

{
  :type :Tuple(
    :Option( :String )
    :Either( :String :Int32 )
    :Union( :String :Int32 )
    :Boolean
  )
  :body (
    #S "active"    // Warning: Use long-form tag '#Some' (or redundant tag if implied)
    #Right 42      // Warning: Redundant variant tag (Rule B inference)
    #1 "payload"   // Warning: Redundant variant tag (Rule C inference)
    #T             // Warning: Use long-form tag '#TRUE'
  )
}

Canonical Compliant Form:

{
  :type :Tuple(
    :Option( :String )
    :Either( :String :Int32 )
    :Union( :String :Int32 )
    :Boolean
  )
  :body (
    "active"       // Clean implied sum type (Rule A inference)
    42             // Clean implied sum type (Rule B inference)
    "payload"      // Clean implied sum type (Rule C inference)
    #TRUE          // Canonical long-form boolean
  )
}
