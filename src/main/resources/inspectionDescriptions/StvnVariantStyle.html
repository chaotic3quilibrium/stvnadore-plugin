Reports style discrepancies and redundant discriminator tags on algebraic sum types (:Option, :Either, :Union) and boolean literals according to project code style preferences (STVN Spec § 5.2 and § 8.1).

This inspection enforces two distinct style rules:

  1. Redundant Variant Tags: When "Prefer implied algebraic sum types" is enabled in project settings, explicit tags across :body slots and :defs constant values are verified via full-spine Pure-IR equivalence and flagged only when removing them preserves exact value semantics:
    • #Some "text" in :Option(:String) (Rule A inference)
    • #Right 42 in :Either(:String :Int) (Rule B inference)
    • #1 "payload" in :Union(:String :Int) (Rule C inference)
    • Irreducible nested disambiguators such as #Some #None, #Right #None, and #Right #Left "inner" are preserved without warnings so outer sum wrappers never hijack inner tags.
    • Over-specified nested chains such as #Some #Right #None flag only a composable inner-to-outer subset (#Right → #Some #None) that remains safe under batch Fix all execution.
  2. Form Discrepancies (Long vs. Short): Flags sum-type tags and boolean literals that do not match the configured long-form or short-form style preference:
    • Long Form: #Some, #None, #Left, #Right, #TRUE, #FALSE
    • Short Form: #S, #N, #L, #R, #T, #F
    Note: Numeric union branch tags (e.g. #1, #2) possess invariant fixed syntax.

Quick-Fixes Available:

  • Remove redundant tag: Verifies live Pure-IR equivalence, preserves interior line comments, and strips the superfluous discriminator tag (#Some, #Right, #1, etc.).
  • Change tag to #...: Converts short-form tags to long-form or vice versa to align with project settings.

Example (Redundant Tag & Form Discrepancy):

{
  :type :Tuple(
    :Option(:String)
    :Either(:String :Int)
    :Union(:String :Int)
    :Boolean
  )
  :body (
    #S "active"    // Warning: Use long-form tag '#Some' (or redundant tag if implied)
    #Right 42      // Warning: Redundant variant tag (Rule B inference)
    #1 "payload"   // Warning: Redundant variant tag (Rule C inference)
    #T             // Warning: Use long-form tag '#TRUE'
  )
}

Canonical Compliant Form:

{
  :type :Tuple(
    :Option(:String)
    :Either(:String :Int)
    :Union(:String :Int)
    :Boolean
  )
  :body (
    "active"       // Clean implied sum type (Rule A inference)
    42             // Clean implied sum type (Rule B inference)
    "payload"      // Clean implied sum type (Rule C inference)
    #TRUE          // Canonical long-form boolean
  )
}
