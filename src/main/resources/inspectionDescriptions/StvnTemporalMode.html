Reports missing or conflicting mode and scale facets on temporal type declarations (:TimeEpoch and :DateTime) to enforce STVN 2.0.0 temporal governance.

Temporal Mode & Scale Invariants (E008 / ERR_MISSING_TEMPORAL_FACET & MUTUALLY_EXCLUSIVE_BOUNDS):

  • The :TimeEpoch temporal primitive requires one explicit scale facet (#ns, #us, #ms, or #s, e.g. { #ms } :TimeEpoch), pinned directly to the :TimeEpoch constructor token when omitted.
  • The :DateTime temporal primitive requires one explicit mode facet (#offset, #zoned, or #audited), pinned directly to the :DateTime constructor token when omitted.
  • Temporal scale facets (#ns, #us, #ms, #s) and temporal mode facets (#offset, #zoned, #audited) are mutually exclusive within a single metadata block, pinning E008 / MUTUALLY_EXCLUSIVE_BOUNDS to each conflicting facet beyond the first.

Provides automated intention quick-fixes to insert default temporal facets, retain a single scale or mode facet, or remove a conflicting facet (Remove conflicting facet '<facet>').
