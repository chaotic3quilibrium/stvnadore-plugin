Reports missing or conflicting mode and unit facets on temporal type declarations (:TimeEpoch and :DateTime) to enforce STVN 2.0.0 temporal governance.

Temporal Mode & Unit Invariants (ERR_MISSING_TEMPORAL_FACET / ERR_MUTUALLY_EXCLUSIVE):

  • The :TimeEpoch temporal type requires an explicit #unit facet (e.g. { #unit #ms } :TimeEpoch).
  • The :DateTime temporal type requires an explicit mode facet (#offset, #zoned, or #audited).
  • Temporal mode facets #offset, #zoned, and #audited are mutually exclusive on a single type declaration.

Provides automated intention quick-fixes to supply default temporal facets.
