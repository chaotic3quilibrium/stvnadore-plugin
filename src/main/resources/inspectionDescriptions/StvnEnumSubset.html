Reports violations of Strong Typed Value Notation (STVN) Enum and Enum Subset rules across :defs, :type, and :body (STVN Spec §4.8):

  • Relative Root Order Violation (E015 / ENUM_SUBSET_ORDER_VIOLATION): Variants inside #filterIncl or #filterExcl must match the monotonic declaration order of the root :Enum. Provides an automatic in-place reordering quick-fix.
  • Monotonic Narrowing Violation (E014 / ENUM_SUBSET_NOT_SUBSET): Every variant in a filter facet must be active in the immediate parent enum.
  • Complete Exclusion Violation (E016 / ENUM_SUBSET_EMPTY): Filtered enum subsets must retain at least one active variant.
  • Mutual Exclusivity Violation (E008 / MUTUALLY_EXCLUSIVE_BOUNDS): A single metadata block must not contain both #filterIncl and #filterExcl; pins the error to the second filter facet with Remove conflicting facet '<facet>'.
  • Subset-Excluded Payload & Constant Values (E012 / ERR_CONSTRAINT_VIOLATION): Flags root enum variants excluded by a governing :EnumSubset in both :body slots and nominal #CONST definitions while exempting declared #CONST references.
  • Undeclared Enum Variants (E028 / ERR_TYPE_MISMATCH): Flags undeclared variant tags against nominal or inline :Enum and :EnumSubset schemas in both :body slots and #CONST definitions.

Quick-Fixes Available:

  • Sort variants to match root enum declaration order: Reorders out-of-order variants in a filter list to match the canonical root enum declaration order.
  • Remove conflicting facet: Deletes a conflicting #filterIncl or #filterExcl facet.
  • Replace with '<#VARIANT>': Offers deterministic per-variant replacement actions for every active variant in declaration order.

Example (Root Ordering Violation):

:defs {
  :Priority :Enum [ #LOW #MEDIUM #HIGH #CRITICAL ]
  // Error: Root ordering violation (:InvalidOrder): variant '#MEDIUM' violates monotonic root enum declaration order
  :InvalidOrder { #filterIncl [ #HIGH #MEDIUM ] } :Priority
}

Correct Form:

:defs {
  :Priority :Enum [ #LOW #MEDIUM #HIGH #CRITICAL ]
  :ValidOrder { #filterIncl [ #MEDIUM #HIGH ] } :Priority
}
