Reports violations of Strong Typed Value Notation (STVN) Enum Subset Filtering rules (STVN Spec §4.8):

  • Relative Root Order Violation: Variants inside #filterIncl or #filterExcl must match the relative declaration order of the root :Enum. Provides an automatic in-place reordering quick-fix.
  • Monotonic Narrowing Violation: Every variant in a filter facet must exist in the immediate parent type's allowed variant set.
  • Mutual Exclusivity Violation: A single metadata block must not contain both #filterIncl and #filterExcl.
  • Target Attachment Violations: Filter facets must not attach to inline enum constructors, non-enum primitives, or constants.
  • Non-Empty Constraints: Filter bracket lists must not be empty, and #filterExcl must not exclude all parent variants.

Quick-Fixes Available:

  • Sort variants to match root enum declaration order: In-place AST rewrite that reorders out-of-order variants in the filter list to match the canonical root enum declaration order.

Example (Root Ordering Violation):

:defs {
  :Priority :Enum [ #LOW #MEDIUM #HIGH #CRITICAL ]
  // Error: Root ordering violation: variant #MEDIUM does not match relative declaration order of root :Enum :Priority
  :InvalidOrder { #filterIncl [ #HIGH #MEDIUM ] } :Priority
}

Correct Form:

:defs {
  :Priority :Enum [ #LOW #MEDIUM #HIGH #CRITICAL ]
  :ValidOrder { #filterIncl [ #MEDIUM #HIGH ] } :Priority
}
