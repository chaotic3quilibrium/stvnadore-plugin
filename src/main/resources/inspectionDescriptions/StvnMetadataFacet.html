Reports invalid metadata facets, incomplete boolean trait facets, empty blocks, and conflicting facets on type declarations and constant definitions to enforce STVN 2.0.0 language governance (STVN Spec §3 & §5).

Empty Sections and Metadata Blocks (ERR_EMPTY_META_BLOCK / ERR_EMPTY_DEFS_BLOCK / ERR_EMPTY_METADATA_BLOCK / ERR_EMPTY_DIRECTIVE_BLOCK):

  • Empty root :meta {} sections are prohibited (E039). Declare document identity facets (#name, #domain, #kind), or omit :meta when optional for the filename.
  • Empty root :defs {} sections are prohibited (E002). Declare at least one type or constant definition, or omit :defs in payload documents.
  • Empty metadata blocks {} on root :type sections, type definitions, or constant definitions are invalid (E003). Specify valid constraint facets or remove {}.
  • Empty directive blocks {} in :use or :include statements are invalid. Specify {#strip}, alias mappings, or delete {}.

Incomplete & Invalid Boolean Trait Facets (E008 / ERR_INCOMPLETE_TRAIT_FACET & ERR_INVALID_METADATA_FACET):

  • Trait and formatting facets #preserveIndent, #equatable, and #comparable require an explicit boolean argument (#TRUE, #FALSE, or a boolean #CONST reference).
  • Bare declarations (such as { #preserveIndent }, { #equatable }, or { #comparable }) report E008 / ERR_INCOMPLETE_TRAIT_FACET and offer CompleteTraitFacetQuickFix to append a non-redundant boolean literal while preserving sibling facets.

Root :meta Facet Governance (ERR_INVALID_METADATA_FACET / ERR_DUPLICATE_METADATA_FACET):

  • Only #name, #domain, and #kind are permitted in :meta blocks. Unknown facet tags (such as #author) and duplicate facets are rejected with E008.

Duplicate & Conflicting Facets (ERR_DUPLICATE_METADATA_FACET / MUTUALLY_EXCLUSIVE_BOUNDS):

  • Each facet keyword may appear at most once per metadata block. Duplicate declarations (e.g. { #size 53 #size 1 }) are prohibited.
  • Co-declaring #size and #exact on :Float triggers E008 / MUTUALLY_EXCLUSIVE_BOUNDS on the second conflicting facet with Remove conflicting facet '<facet>'.

Nominal Type Resolution and Undeclared Type Bailout:

  • Facet compatibility evaluates against the canonical underlying primitive or constructor of declared nominal types.
  • If a nominal base type is undeclared or unresolved, facet validation bails out immediately without emitting facet rejection errors. Type resolution errors are reported exclusively by compiler diagnostic ERR_UNDEFINED_TYPE on the type token.

Permitted Facet Matrix (STVN Spec §3 & §5):

  • Discrete Integer (:Int): #equatable, #comparable, #size, #unsigned, #minIncl, #maxExcl. Closed upper bounds (#maxIncl) and open lower bounds (#minExcl) are strictly prohibited (ERR_DISCRETE_BOUND_KIND_PROHIBITED).
  • Continuous Floating-Point (:Float): #equatable, #comparable, #size, #minIncl, #maxIncl, #minExcl, #maxExcl.
  • Exact Decimal ({ #exact } :Float): #equatable, #comparable, #exact, #minIncl, #maxExcl. Discrete exact floats prohibit #maxIncl and #minExcl.
  • String (:String): #equatable, #comparable, #regex, #minSize, #maxSize, #preserveIndent. Fixed dimension #size is prohibited.
  • Boolean (:Boolean): #equatable.
  • Temporal Epoch (:TimeEpoch): Requires bare scale flag #ns, #us, #ms, or #s. Permits #equatable, #comparable, #minIncl, #maxExcl. Prohibits #maxIncl and #minExcl.
  • Temporal DateTime (:DateTime): Requires mode facet #offset, #zoned, or #audited. Permits #equatable, #comparable, #minIncl, #maxExcl. Prohibits #maxIncl and #minExcl.
  • Enum Types (:Enum): #equatable, #comparable, #filterIncl, #filterExcl.
  • Associative Map (:Map): #invertible.
  • Constants: Metadata facets are strictly prohibited on constant definitions.
  • Directives: #strip is valid strictly in :use and :include statements and prohibited on type declarations.

Provides automated quick-fixes to complete bare trait facets, delete empty blocks, remove invalid facets, remove duplicate facets, or remove conflicting facets.
