Reports invalid metadata facets, empty blocks, and prohibited interval bounds on type declarations and constant definitions to enforce STVN 2.0.0 language governance (STVN Spec § 3 & § 5).

Empty Blocks (ERR_EMPTY_METADATA_BLOCK / ERR_EMPTY_DIRECTIVE_BLOCK):

  • Empty metadata blocks {} on type or constant definitions are invalid. Specify valid facets or delete {}.
  • Empty directive blocks {} in :use or :include statements are invalid. Specify {#strip}, alias mappings, or delete {}.

Duplicate Facets (ERR_DUPLICATE_METADATA_FACET):

  • Each facet keyword may appear at most once per metadata block. Duplicate declarations (e.g. { #size 53 #size 1 }) are prohibited.

Nominal Type Resolution and Undeclared Type Bailout:

  • Facet compatibility evaluates against the canonical underlying primitive or constructor of declared nominal types.
  • If a nominal base type is undeclared or unresolved, facet validation bails out immediately without emitting facet rejection errors. Type resolution errors are reported exclusively by compiler diagnostic ERR_UNDEFINED_TYPE on the type token.

Permitted Facet Matrix (STVN Spec § 3 & § 5):

  • Discrete Integer (:Int): #equatable, #comparable, #size, #unsigned, #minIncl, #maxExcl. Closed upper bounds (#maxIncl) and open lower bounds (#minExcl) are strictly prohibited (ERR_DISCRETE_BOUND_KIND_PROHIBITED).
  • Continuous Floating-Point (:Float): #equatable, #comparable, #size, #minIncl, #maxIncl, #minExcl, #maxExcl.
  • Exact Decimal ({ #exact } :Float): #equatable, #comparable, #exact, #minIncl, #maxExcl. Discrete exact floats prohibit #maxIncl and #minExcl.
  • String (:String): #equatable, #comparable, #regex, #minSize, #maxSize, #preserveIndent. Fixed dimension #size is prohibited.
  • Boolean (:Boolean): #equatable.
  • Temporal Epoch (:TimeEpoch): Requires bare scale flag #s, #ms, #us, or #ns. Permits #equatable, #comparable, #minIncl, #maxExcl. Prohibits #maxIncl and #minExcl.
  • Temporal DateTime (:DateTime): Requires mode facet #offset, #zoned, or #audited. Permits #equatable, #comparable, #minIncl, #maxExcl. Prohibits #maxIncl and #minExcl.
  • Enum Types (:Enum): #equatable, #comparable, #filterIncl, #filterExcl
  • Associative Map (:Map): #invertible.
  • Constants: Metadata facets are strictly prohibited on constant definitions.
  • Directives: #strip is valid strictly in :use and :include statements and prohibited on type declarations.

Provides automated quick-fixes to delete empty blocks, remove invalid facets, or remove duplicate facets.
