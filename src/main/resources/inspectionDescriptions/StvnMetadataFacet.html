Reports invalid metadata facets and empty blocks in type declarations, constant definitions, and module directives to enforce language governance.

Empty Blocks (ERR_EMPTY_METADATA_BLOCK / ERR_EMPTY_DIRECTIVE_BLOCK):

  • Empty metadata blocks {} on type or constant definitions are invalid. Specify valid facets or delete {}.
  • Empty directive blocks {} in :use or :include statements are invalid. Specify {#strip}, alias mappings, or delete {}.

Permitted Facet Matrix (ERR_INVALID_METADATA_FACET):

  • Numeric Types (:Int*, :Uint*, :Float*): #equatable, #comparable, #minIncl, #maxIncl, #minExcl, #maxExcl
  • String Types (:String*): #equatable, #comparable, #regex, #preserveIndent
  • Enum Types (:Enum): #equatable, #comparable, #filterIncl, #filterExcl
  • Constants: Metadata facets are strictly prohibited on constants.
  • Directives: #strip is valid strictly in :use and :include statements and prohibited on type declarations.

Provides automated quick-fixes to delete empty blocks or remove invalid facets.
