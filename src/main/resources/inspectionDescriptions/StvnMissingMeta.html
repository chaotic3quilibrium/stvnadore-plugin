Audits definitions schema documents (.stvn_d, .stvn_di, and .stvn_bd) and modular payload documents (.stvn_i and .stvn_b) for a mandatory root metadata (:meta) section and a matching #kind facet.

Every definitions schema and modular payload document must declare a root :meta section before its definitions or body section, specifying canonical metadata facets (#name, #domain, and #kind).

Quick-Fixes:

  • Inserts a canonical root :meta section with defaulted schema name, domain, and document kind matching the file extension.
  • Inserts a missing #kind facet at canonical Tier 3 inside an existing non-empty :meta section, or updates a mismatched #kind value.
