Audits definitions schema documents (.stvn_d and .stvn_di) and modular payload documents (.stvn_i) for a mandatory root metadata (:meta) block.

Every definitions schema and modular payload document must declare a root :meta block preceding its definitions or body block, specifying canonical metadata facets including #name, #domain, and #kind.

Quick-Fix:

Inserts a canonical root :meta block with defaulted schema name, domain, and document kind matching the file extension.
