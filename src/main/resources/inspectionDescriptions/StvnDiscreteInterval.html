Validates STVN 2.0.0 discrete interval bound kinds and effective interval bound ordering across numeric, string, and temporal schemas (STVN Spec § 5.1.2 and § 7.3).

Discrete Half-Open Interval Invariant (ERR_DISCRETE_BOUND_KIND_PROHIBITED):

  • Discrete domains (:Int, { #exact } :Float, :TimeEpoch, and :DateTime) require half-open intervals [minIncl, maxExcl).
  • Closed upper bound #maxIncl and open lower bound #minExcl are pinned strictly to the 8-character facet keyword so bound #CONST references retain clean hover documentation.
  • Column-preserving quick-fixes replace #maxIncl → #maxExcl or #minExcl → #minIncl (and shift integer bounds <N> → <N+1>) in place without disturbing multi-space alignment or trailing comments.

Interval Ordering and Empty Domain Governance (ERR_INVERTED_RANGE, ERR_EMPTY_INTERVAL_DOMAIN):

  • Pins adjacent local bound pairs (|minIdx - maxIdx| == 1) strictly to the contiguous [earlier .. later) sub-range so braces and unrelated sibling facets remain clear.
  • Pins non-adjacent local bound pairs strictly to the later bound entry while keeping quick-fix access on both bounds.
  • Delegates tripartite :DateTime bound mode validation (#offset, #zoned, #audited) to the STVN compiler without secondary interval cascades.

Provides automated intention quick-fixes to convert bounds to canonical half-open form and swap inverted lower and upper bounds in place.
