Validates that integer and continuous floating-point literals assigned to typed constant declarations fit within the physical bit-width boundaries of their declared schema types.

Derives capacity bounds using arbitrary-precision integers for :Int and IEEE-754 boundaries for continuous :Float (32-bit single precision or 64-bit double precision), flagging any constant literal whose value falls out of physical range.

Example (Range Violation):

:defs {
  // Error: Integer literal 300 out of range for { #size 8 } :Int [-128, 127]
  #MAX_VAL { #size 8 } :Int 300

  // Error: Float literal 3.5e38 out of range for { #size 32 } :Float [-3.4028235E+38, 3.4028235E+38]
  #MAX_FLOAT { #size 32 } :Float 3.5e38
}
