Validates that integer literals assigned to typed constant declarations fit within the physical bit-width boundaries of their declared integer types.

Derives capacity bounds using arbitrary-precision integers for :Int qualified with #size <N> and #unsigned facets, flagging any constant literal whose value falls out of range.

Example (Range Violation):

:defs {
  // Error: Integer literal 300 out of range for { #size 8 } :Int [-128, 127]
  #MAX_VAL { #size 8 } :Int 300
}
