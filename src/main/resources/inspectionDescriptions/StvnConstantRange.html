Validates that integer literals assigned to typed constant declarations fit within the physical bit-width boundaries of their declared integer types.

Derives capacity bounds using arbitrary-precision integers for :Uintn and :Intn types, flagging any constant literal whose value falls out of range.

Example (Range Violation):

:defs {
  // Error: Integer literal out of range for :Int8 [-128, 127]
  #MAX_VAL :Int8 300
}
