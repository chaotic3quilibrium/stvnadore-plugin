Detects prohibited trailing slash characters in :use target specifications and :package enclosure paths.

Package paths in :package enclosures and target paths in :use statements must end with an identifier segment without trailing slashes.

Examples (Prohibited Trailing Slash):

:defs {
  // Error: Trailing slash prohibited in :package path
  :package :com/example/util/ {
    :Port :Int
  }

  // Error: Trailing slash prohibited in :use target
  :use [ :com/example/util/ ]
}
